# Soqotri Restaurant Website | موقع مطعم سقطري

A beautiful, responsive multilingual website for a Soqotri restaurant in Paris. Built with HTML, CSS, and vanilla JavaScript.

موقع جميل ومتجاوب متعدد اللغات لمطعم سقطري في باريس. تم بناؤه بلغات HTML و CSS و JavaScript.

## Features | المميزات

### 🌍 Multilingual Support | دعم متعدد اللغات
- **Arabic (العربية)** - Default language with RTL support
- **French (Français)** - Full French translation
- **English (English)** - Complete English translation
- Language preference saved in localStorage
- Dynamic content switching without page reload

### 📱 Responsive Design | تصميم متجاوب
- Mobile-first approach
- Optimized for all screen sizes
- Touch-friendly navigation
- Adaptive layouts

### 🎨 Features | المميزات
- **Hero Section** - Eye-catching landing page
- **About Section** - Restaurant story and features
- **Menu Section** - Complete food menu with categories
  - Appetizers | المقبلات
  - Main Dishes | الأطباق الرئيسية
  - Seafood | المأكولات البحرية
  - Desserts | الحلويات
  - Drinks | المشروبات
- **Gallery** - Image gallery with modal viewer
- **Contact Form** - Table reservation with validation
- **Smooth Animations** - Scroll animations and transitions

### 🛠️ Technologies | التقنيات المستخدمة
- HTML5
- CSS3 (with CSS Variables)
- Vanilla JavaScript (ES6+)
- Google Fonts (Cairo & Poppins)
- SVG Graphics

## How to Use | كيفية الاستخدام

### Local Development | التطوير المحلي
1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!

### Changing Language | تغيير اللغة
Click on the language buttons in the navigation bar:
- 🇾🇪 العربية (Arabic)
- 🇫🇷 Français (French)
- 🇬🇧 English (English)

### Menu Categories | فئات القائمة
Filter menu items by clicking on category buttons:
- All | الكل
- Appetizers | المقبلات
- Main Dishes | الأطباق الرئيسية
- Seafood | المأكولات البحرية
- Desserts | الحلويات
- Drinks | المشروبات

### Contact Form | نموذج الاتصال
Fill in the booking form to reserve a table:
- Full Name | الاسم الكامل
- Email | البريد الإلكتروني
- Phone | رقم الهاتف
- Date & Time | التاريخ والوقت
- Number of Guests | عدد الأشخاص
- Special Notes (optional) | ملاحظات خاصة
